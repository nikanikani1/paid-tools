# 支付 + R2 上线记录（2026-11-12）

## 真实链路（已验证）

1. 前端 BuyButton → `POST /api/checkout`（server 端定价，不信任前端金额）
2. `orders` 写入 R2：`orders/<site>/<orderId>.json`
3. Waffo `POST /v1/actions/checkout/create-session`（RSA-SHA256）→ `pancake.waffo.ai` URL
4. Waffo webhook → `/api/webhooks/waffo`（`X-Waffo-Signature: t=..,v1=..`）
5. 订单 `paid` → 任务 API 校验额度并扣减
6. Replicate 输出 → 服务端 PUT 到 R2 → 7 天 presigned URL
7. job 记录写 R2：`jobs/<site>/<jobId>.json`（Worker 重启发也可轮询）

## 实测

- 线上 checkout：voice/headshot 均返回真实 `checkoutUrl`
- 未支付 `POST /api/jobs` / `/api/orders`：402
- 签名 webhook 测试（临时公钥）→ 订单 paid；恢复真实公钥
- 真实 A 站：demucs prediction 完成，4 stems 全部进 R2，`meta.r2=true`
- 真实 B 站：Kontext + face-swap 完成，1 张进 R2
- 线上无订单任务仍 402
